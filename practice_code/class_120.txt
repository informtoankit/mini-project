GitHub Actions

GitHub Actions ek CI/CD tool hai jo GitHub ke andar built-in available hota hai. Jab bhi developer code me changes karke GitHub repository me push karta hai, GitHub Actions automatically trigger ho sakta hai aur predefined workflow execute karta hai.

GitHub Actions ka use software development process ko automate karne ke liye kiya jata hai. Ye automatically application build kar sakta hai, tests run kar sakta hai, Docker image create kar sakta hai aur application ko deployment environment me deploy bhi kar sakta hai. Isse manual effort kam hota hai aur deployment process reliable ban jata hai.

What is a Workflow?

A Workflow is a set of instructions or automated steps executed in a predefined order to complete a task.

Example GitHub Actions Workflow:

Code Push
    ↓
Build
    ↓
Test
    ↓
Docker Build
    ↓
Deploy

Each step automatically executes after the previous step succeeds.

Interview Definition

A workflow is a sequence of automated tasks executed in a predefined order to achieve a specific objective, such as building, testing, and deploying an application. In GitHub Actions, workflows are defined using YAML files and are triggered by events such as code pushes, pull requests, or scheduled executions.
